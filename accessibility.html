Accessibility Statement

Last updated: July 31, 2026

Not Your Average Tech is committed to making this website useful and accessible to as many people as possible, including people with disabilities.

On this page

  1. Commitment
  2. Accessibility features
  3. Compatibility

Commitment

The goal is to provide a website that can be perceived, understood, navigated, and used by a broad range of visitors. Accessibility is treated as an ongoing part of maintaining and improving this website.

Work is guided by widely accepted accessibility practices and the Web Content Accessibility Guidelines (WCAG). This statement does not claim that every page has been independently audited or certified.

Accessibility features

Measures used on these policy pages and across the website include:

  • Semantic headings and page landmarks that support screen-reader navigation.
  • Keyboard-accessible navigation and controls.
  • Visible keyboard focus indicators and a skip-to-content link on these policy pages.
  • Descriptive page titles, link text, labels, and alternative text for meaningful images.
  • Responsive layouts that support browser zoom and a range of screen sizes.
  • Support for reduced-motion preferences where animation is used.

Compatibility

The site is designed for current versions of major browsers and common assistive technologies.

Results can vary with older browsers, custom settings, browser extensions, or assistive technology combinations.

Known limitations

Some third-party services, embedded content, downloadable files, or older project examples may not provide the same level of accessibility as the main website.

If you encounter content that is difficult to access, an alternative format or another way to receive the information will be provided when reasonably possible.

Feedback and assistance

If you have trouble using any part of this site, need information in another format, or want to report an accessibility issue, please share the page address, the problem you encountered, and the browser or assistive technology you were using if you are comfortable doing so.
